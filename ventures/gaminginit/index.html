The problem

Game servers have rich activity. None of it is visible outside the game.

0

External visibility by default

Who’s online, what map is running, who won the last match — none of it reaches players who aren’t already in-game.

No hub

Community scattered across Discord

Stats, announcements, and moderation all happen in separate Discord channels with no shared source of truth that players outside Discord can reach.

Manual

Staff moderation is tedious

Without tooling, every warn, kick, ban, or team-switch requires a server admin to log in directly. No audit trail, no convenience.

How it works

A public website and a Discord bot, built as one platform.

gaminginit is two products that share the same RCON data source: a public Cloudflare Pages site at gaminginit.com, and a Discord bot (wardogs-discord-bot) that pipes the same information into the community’s server.

Live server dashboard

Real-time player count, active map with its own colour, current faction breakdown and a full player list — updated continuously without a page refresh.

Match summaries and history

Every completed match is recorded: winner, factions, scores and duration. A 24-hour chart and a 14-day activity chart show when the server is busiest.

Leaderboard

Top-ranked players surfaced publicly, with a call to action for seeder VIPs who keep the server alive at low population.

Staff moderation in Discord

The full admin command suite — /warn, /kick, /ban, /switchteam, /setnextmap, /changemap and more — is available to Discord members with the Staff role, with clear failure reasons when something goes wrong.

Bot personality

In-game broadcast messages and Discord embeds reflect the server’s character: faction-specific jokes at the halfway point, varied lines so nothing gets stale, and a 5-minute grace period before low-population alerts fire.

Map identity

Each map — Bakurani, Ozeti, Zestafona — has its own distinct colour in Discord and on the site, making it easy to read at a glance what’s running.

Where we are · October 2026

Live and growing — launched 30 Sep 2026.

The full platform launched on 30 Sep 2026: the public community website at gaminginit.com and the wardogs-discord-bot reached production together. In the days since, the platform has expanded significantly. On 1–2 Oct: public player pages, a busiest-times chart, a self-updating live status feed in Discord, in-game seeding broadcasts, a /seednow command for staff, accurate match results for tight finishes, and reliable ban enforcement. On 3 Oct: a new Teams page showing faction win rates overall and per map; the seeding page now lists top seeders and seeder VIP holders; the home page has been split into focused sub-pages with a “Play with us” section; the busiest-times chart now uses a typical day (crashes excluded) so one bad day cannot skew the picture; the bot now checks players’ Steam accounts for suspicious activity and alerts staff only on the highest-risk accounts; staff can save and schedule named map rotations; permanent VIP is available; and the staff page is reorganised into Players, Alerts and Admin tabs with a filterable moderation log. On 4 Oct: VIP changes are now logged with who made them and why; map rotations start from the first map so switching never repeats a map; the staff page has a live kill feed and 30-day kill history with per-weapon headshot analysis that flags unusual patterns without penalising snipers for sniping; the longest kill record now counts only hand-held weapons; match roundups now include a full awards section covering top players by role and individual shout-outs; all 34 weapons in the game are now named, with past kills updated automatically; staff can write their own in-game messages for any bot broadcast; and Discord team-selection menus now show each faction in its own colour. On 5 Oct: server status posts now include the server ID and step-by-step join instructions so players can join directly from within the game; command errors from bot commands are now private to whoever ran them rather than visible to the whole channel; “Match over” posts and /lastmatch now link to the specific match page on the website; and the staff page now tracks each player’s join and leave times, keeping 30 days of session history with the current session shown first. On 6 Oct: seeding alerts now stay quiet between 9 pm and 6 am UK time so the community is not pinged overnight; the bot checks the game server less often — reading the ban list every 10 minutes and the map rotation only on map changes — so matches run more smoothly; new players now receive a private in-game welcome with the server rules, the Discord link and the website two minutes after joining; and staff can now see today’s team-kill details on any player directly in the /player command. On 7 Oct: the K/D leaderboard now requires 10 hours of play in the last 30 days to qualify, replacing a match-count threshold that could be reached in a single brief visit; staff can mark any player as private so their name is replaced by “[private profile]” everywhere the public can see; a new Weapon rules tab lets staff configure the bot to automatically warn or kick players who kill with banned weapons; staff can mark a flagged player as “checked” to clear them from the active watch list for the day; the staff page has been reorganised into Moderation and Server settings sections, with alerts and player details shown side by side and one-click ban/kick buttons; the “Admin” tab is renamed to “Bans and VIP”; and rotation schedule dropdowns are fixed and weapon-rule searches are now case-insensitive. On 8 Oct: match results that end with equal scores are now recorded and displayed as “no result” on the website, in Discord match posts, and in faction win-rate statistics — matching how the game itself handles these outcomes. On 9 Oct: Season in Review is now live — each player can see a personal slideshow of their Season 1 stats, faction wins, kill streaks and worst moments, with animated slides, optional music and confetti on the highlights; the full Season 1 server-wide roundup goes live on 15 October when the server wipes. The longest kill distance now only counts hand-held weapons. The K/D leaderboard now requires 10 completed matches to qualify, replacing the previous hours-played rule. Staff sign-in sessions now last 36 hours. Bot in-game messages skip any line used recently so the same message doesn’t repeat too quickly.

Website

Cloudflare Pages site with live server stats, match history, leaderboard, a player page for everyone who has played in the last 90 days, a “busiest times” view drawn from a typical day, a Teams page for faction win rates, and a seeding page listing top seeders and VIP holders. The home page links to each section. Updated continuously without a page refresh.

Discord bot

Cloudflare Worker running wardogs-discord-bot. Posts seeding, live and low-pop alerts; keeps a self-updating live-status message; handles the full staff command suite including /seednow and permanent VIP; broadcasts seeding calls in-game every 5 minutes; checks Steam accounts for suspicious activity and alerts on the riskiest; supports named map rotations that always start from the beginning; bans take full effect; seeding credit counts correctly after crashes; VIP changes logged with reason; all 34 weapons named; live kill feed with 30-day history and headshot analysis; longest kill counts hand-held weapons only; roundup awards; staff-customisable in-game messages; faction colours in Discord menus; server ID and join instructions on status posts; command errors private to whoever ran them; match posts link to the specific match; session history per player for staff; seeding alerts quiet at night (9 pm–6 am UK); new-player in-game welcome with rules, Discord and website; team-kill details per player in /player; fewer RCON calls for smoother matches; K/D board requires 10 completed matches to rank; private profiles hide players from the public on request; Weapon rules tab for auto-warn or auto-kick on banned weapons; staff can mark flagged players as checked to clear them from the watch list; equal-score map endings recorded as “no result” in all match posts and stats.

Next steps

Broader community features as the WARDOGS server grows. The platform is designed to serve any game server that exposes a compatible RCON API.
