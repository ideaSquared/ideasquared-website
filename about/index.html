About

One person, building in the evenings.

ideaSquared is run by Alex Jenkinson, a software developer in Macclesfield. It takes ideas from first spark to something people can use, one venture at a time.

The studio

Small on purpose.

ideaSquared runs on 6 to 16 hours a week, alongside a full-time job. That sets the pace: one venture in focus, and plans made against real hours.

Each idea becomes a proposal with go and stop numbers before real time or money goes in. Code is open source where it can be. When something doesn’t work, we say so and write up why.

The first venture is AdoptDontShop. It helps UK rescue organisations list animals and handle adoption applications in one place. Its closed beta with local rescues is planned for early 2027.
