About ideaSquared.

Use either version as written.

Short (35 words)

ideaSquared is a UK venture studio founded by Alex Jenkinson. It builds digital products in the open and tests each one against clear numbers before growing it. Its first venture is AdoptDontShop.

Long (80 words)

ideaSquared is a UK venture studio founded by Alex Jenkinson in Macclesfield. It takes ideas from first spark to something people can use, one venture at a time. Each idea becomes a proposal with go/no-go numbers before real time or money goes in. Code is open source where it can be. The first venture, AdoptDontShop, helps UK rescue organisations list animals and handle adoption applications in one place. Its closed beta with local rescues is planned for early 2027.
