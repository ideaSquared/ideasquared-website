The problem

The path to adoption should be simpler than the path to a breeder.

100,000+ pets enter UK rescues every year, but adoption is slow and fragmented. Buying from a breeder is easier than adopting from a rescue.

Rescues lack modern tools

Most run on spreadsheets, email and Facebook posts. Listings, applications, home checks and outcomes all live in different places — or no place at all.

Adopters bounce between sites

Charity websites have inconsistent UX. The under-40 segment expects Tinder-quality discovery, not a PDF form.

The solution

A consumer app plus rescue SaaS that owns the full journey.

For adopters

Swipe-based discovery with smart matching on lifestyle, home and experience. One profile, applications across multiple rescues, clear status tracking from application to home check to adoption.

For rescues

A dashboard for listings, applications, home checks and outcomes. Built-in messaging and document handling. Analytics on time-to-adoption and applicant quality.

Go-to-market

Cluster, then influence, then national.

Two-sided marketplaces don't survive a national cold start. We onboard density first.

Phase 1 · Cluster

Convert the 5 lister LOIs to signed agreements and onboard 50–100 invited adopters from the existing waitlist into a single-region closed beta. Density before reach.

Phase 2 · Influence

TikTok and Instagram pet creators drive adopter installs alongside organic. Public launch opens the rescue dashboard beyond the closed beta cohort.

Phase 3 · National

20 active listers and the first 100 adoptions by Q1 2027, then UK-wide rollout. Vet, insurer and food-brand partnerships layer on revenue and supply.

Where we are · June 2026

Alpha build is feature-complete. Compliance is the gate.

The core adoption flow ships end-to-end in the alpha. The path to closed beta now runs through legal foundation, the data protection package and platform hardening — not more product code.

Shipped in the alpha

Auth, rescue verification, pet listings with staff permissions, adopter browse/filter/like flow, real-time messaging, full Docker dev + prod environment, OpenTelemetry distributed tracing, and Sigstore container signing. Microservices migration complete (Phase 11) — all ten domain services (auth, pets, rescue, applications, matching, notifications, chat, moderation, audit, storage) now run as independent gRPC microservices behind a strangler-fig gateway; the legacy monolith has been fully deleted. Security hardening includes non-root production containers, fully parameterised CMS queries, and authenticated WebSocket handshakes.

Three frontends, one platform

React 18 + Vite + styled-components across the adopter portal, rescue dashboard and internal admin. Node 20 + Fastify + Sequelize on PostgreSQL 16 + PostGIS and Redis 7, fronted by Nginx. All ten domain services communicate over gRPC + NATS JetStream in a fully distributed microservices architecture; the monolith is gone.

Demand signal preserved

5 lister letters of intent and a 1,000+ adopter waitlist carried over from the prior cycle. Cluster-first: we convert the LOIs to signed lister agreements at closed beta, not before.
